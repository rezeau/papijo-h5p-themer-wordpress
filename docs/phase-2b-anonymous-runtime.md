# Phase 2B — integrated anonymous runtime (unreleased)

> Public documentation projection: machine paths, private evidence references, local host/profile identifiers and verification fingerprints are replaced with placeholders. Technical findings and original checkpoint claims are retained; historical operator commands are records, not current deployment instructions. The private development original is preserved. Use CONTRIBUTING.md for current commands.

Anonymous delivery now selects the adapted companion controller directly, through
Theme_Attachment. Permission remains independent and default-off. The obsolete
Phase 2A readiness gate is removed. No takeover, cross-plugin source pins,
development flags, or historical runtime protocols are included.

The controller retains the companion general-mode per-player ownership, qualification,
renewal, stale-response, lifecycle and page-wide terminal failure logic. There is
one page selector above the first admitted activity in DOM order. A native details
control contains the accessible fieldset and starts closed. Expansion is not saved.
Status messages remain outside the closed disclosure so reload requests are visible.
The new localStorage namespace is pjh5pwp:anonymous:v1:<encoded canonical home>:,
with independent JSON Theme and Density tokens. No standalone migration occurs.

The anonymous transport uses Phase 2A's six-field schema and version-1 public
response. Default/authenticated transport adds an expected-audience assertion from
the server-rendered controller tag; a mismatch returns a descriptor-free 409 before
reading account preferences. The existing controller then releases owned styling,
stops, and displays a manual reload request. Its readiness engine was not rewritten.
Anonymous-to-authenticated transitions retain the companion's release-and-stop path.

Known limitations remain: 64 distinct admitted IDs; repeated IDs excluded; new IDs
inserted after manifest creation unsupported; known iframe replacement requires fresh
admission; the existing readiness budgets apply. Anonymous appearance initially stays
visible with the accepted brief styling delay. No unrelated readiness fix is claimed.
