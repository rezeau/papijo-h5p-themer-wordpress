# Papi Jo H5P Themer for WordPress 0.3.0

Anonymous visitors can now select their H5P Theme and Density using the main plugin.
The standalone Anonymous companion is no longer required and should be deactivated.

- Independent administrator opt-in, disabled by default.
- One initially collapsed H5P appearance selector above the first eligible activity;
  saved appearance applies automatically, with Theme, Density and Restore defaults.
- Site-scoped browser-local anonymous choices, independent of account preferences.
- Published custom Themes and safe unavailable-Theme fallback.
- Simpler end-user Theme dropdowns, preserving existing saved Core preferences and
  administrator options; quieter collapsed status and accessible fieldset semantics.
- Existing Theme management, color transfer, authenticated preferences, qualified
  iframe/DIV playback and official administration viewer remain available.
- SNORDIAN suspension, identity isolation and runtime safeguards are retained.

Declared requirements remain WordPress 6.5+, PHP 7.4+, single-site and qualified
official H5P/Core API 1.28 integration. Local acceptance used H5P 1.17.10. Existing
readiness, dynamic-content and external-embed limitations remain; no universal
compatibility or unrelated runtime fixes are claimed. See installation documentation.

The maintainer reports 13 Firefox acceptance tests and both interface refinement
tests PASS on 0.3.0-dev.1. Codex did not independently reproduce browser acceptance.
Final preparation changes metadata/documentation only. Essential ZIP/projection
checks are performed; the pre-existing administrator test failure reproduced against
v0.2.1 remains outside scope and is not claimed as a pass. Publication/deployment
of the final package require subsequent approval. Existing public releases remain intact.
